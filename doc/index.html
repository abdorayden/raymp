What is RMP?

RMP (Ray Music Player) is a high-performance, extensible framework built in C with Lua scripting for creating sophisticated terminal user interfaces. Originally conceived as a music player, RMP has evolved into a comprehensive platform for terminal-based applications.

Difference Between RMP and RayMp

RayMp is a software platform that renders templates and plugins with user configurations for a better audio experience using the RMP framework. RMP is a framework with multiple classes and functions that uses C as a backend for better performance. It is used to create templates and plugins for the RayMp software and is also powerful for creating TUI applications in Lua.

RMP Framework API Documentation

Overview

The RMP framework provides a comprehensive terminal-based UI framework with audio playback capabilities. It's designed to create rich terminal applications with features like windows, text styling, drawing primitives, audio control, and more.

Framework Version

RMP api v1.0.0

Supported Lua Version

This API works with Lua version 5.4

Core Components

RMP.Window

Terminal window management with support for creating bordered terminal windows with titles and customizable styling.

-- Example usage
local window = RMP.Window.new("my_window_id")
local vterm = window:createWindow(
    "My Window Title",  -- title
    50,                -- width
    20,                -- height
    1,                 -- x position
    1,                 -- y position
    RMP.FGColors.Brights.White,  -- border color
    RMP.BGColors.NoBrights.Black, -- background color
    RMP.BoxDrawing.LightBorder,   -- border style
    function(x, y, xx, yy)        -- callback function
        local vt = RMP.VirtualTerminal.new()
        vt:writeText(x, y, "Content inside window")
        return vt
    end
)

RMP.Text

Text styling and formatting with ANSI color codes, formatting, and Unicode symbols.

-- Example usage
local text = RMP.Text.new(
    "Styled Text",
    RMP.TextStyle.Bold,
    RMP.FGColors.Brights.Green,
    RMP.BGColors.NoBrights.Black
)
text:setPosition(5, 5)
local vterm = text:render()

RMP.VirtualTerminal

Virtual terminal buffer for drawing operations and merging multiple UI components.

-- Example usage
local vterm = RMP.VirtualTerminal.new()
vterm:writeText(10, 5, "Hello World!", RMP.FGColors.Brights.Yellow)
vterm:drawBox("Title", 1, 1, 30, 10, RMP.BoxDrawing.LightBorder)

RMP.Sound

Audio playback system with support for playlists, volume control, and playback modes.

-- Example usage
local sound = RMP.Sound.new({"track1.mp3", "track2.mp3"})
sound:setVolume(0.8)
sound:setPlayBackMode(RMP.PlaybackMode.LOOP_PLAYLIST)
sound:play()

RMP.Draw

Drawing primitives for creating shapes, lines, and other visual elements in the terminal.

-- Example usage
local draw = RMP.Draw.new()
local vterm = RMP.VirtualTerminal.new()
draw:rectangle(5, 5, 20, 10, RMP.BGColors.NoBrights.Blue, vterm)
draw:circle(15, 10, 5, RMP.FGColors.Brights.Red, vterm)

RMP.Options

Interactive menu system with selection capabilities.

-- Example usage
local options = RMP.Options.new({"Option 1", "Option 2", "Option 3"})
options:setColorFocus(RMP.BGColors.NoBrights.Cyan)
options:next()
local selected = options:getSelected()

RMP.Scroller

Content scrolling mechanism for large datasets.

-- Example usage
local options = RMP.Options.new({"Item 1", "Item 2", "Item 3", "Item 4", "Item 5"})
local scroller = RMP.Scroller.new(3, options)  -- Show 3 items at a time
scroller:nextLine()
local visible_items = scroller:getVisible()

Platform Support

RMP supports multiple platforms with automatic detection:

  • RMP.PlatformType.LINUX - Linux operating systems
  • RMP.PlatformType.WINDOWS - Microsoft Windows
  • RMP.PlatformType.MAC - Apple macOS
  • RMP.PlatformType.UNKNOWN - Other/unknown platform
-- Example usage
local os_type = RMP.getOs()
if os_type == RMP.PlatformType.LINUX then
    print("Running on Linux")
elseif os_type == RMP.PlatformType.WINDOWS then
    print("Running on Windows")
end

Keyboard Keys Mapping

RMP provides comprehensive keyboard key mappings:

Control Keys

RMP.KEY_CTRL_A through RMP.KEY_CTRL_Z

Special Keys

RMP.KEY_ENTER, RMP.KEY_SPACE, RMP.KEY_ESCAPE

Arrow Keys

RMP.KEY_UP, RMP.KEY_DOWN, RMP.KEY_LEFT, RMP.KEY_RIGHT

Function Keys

RMP.KEY_F1 through RMP.KEY_F12

-- Example usage in event handling
function handleKeyEvent(key)
    if key == RMP.KEY_SPACE then
        -- Toggle play/pause
    elseif key == RMP.KEY_UP then
        -- Increase volume
    elseif key == RMP.KEY_DOWN then
        -- Decrease volume
    elseif key == RMP.KEY_CTRL_C then
        -- Exit application
    end
end

Color Support

RMP supports both foreground and background colors with bright and non-bright variants:

Foreground Colors

  • RMP.FGColors.NoBrights.Black through RMP.FGColors.NoBrights.White
  • RMP.FGColors.Brights.Black through RMP.FGColors.Brights.White

Background Colors

  • RMP.BGColors.NoBrights.Black through RMP.BGColors.NoBrights.White
  • RMP.BGColors.Brights.Black through RMP.BGColors.Brights.White
-- Example usage
local vterm = RMP.VirtualTerminal.new()
vterm:writeText(1, 1, "Red text on blue background",
    RMP.FGColors.Brights.Red,
    RMP.BGColors.NoBrights.Blue)

Text Styling Options

RMP provides various text styling options:

  • RMP.TextStyle.Strike - Strikethrough text
  • RMP.TextStyle.Underline - Single underline
  • RMP.TextStyle.Bold - Bold text
  • RMP.TextStyle.Italic - Italic text
  • RMP.TextStyle.Reverse - Reversed background/foreground colors
  • And many more...
-- Example usage
local text = RMP.Text.new("Bold and red",
    RMP.TextStyle.Bold,
    RMP.FGColors.Brights.Red)

Audio Playback Modes

  • RMP.PlaybackMode.ONCE - Play once, then stop
  • RMP.PlaybackMode.LOOP_SINGLE - Loop the current track
  • RMP.PlaybackMode.LOOP_PLAYLIST - Loop the entire playlist
  • RMP.PlaybackMode.SHUFFLE - Play tracks in random order
-- Example usage
sound:setPlayBackMode(RMP.PlaybackMode.LOOP_PLAYLIST)

Animation Patterns

RMP includes numerous animation patterns for loading spinners and other UI elements:

  • Spinners: RMP.AnimationPatterns.Spinner
  • Dots: RMP.AnimationPatterns.Dots
  • Lines: RMP.AnimationPatterns.Line
  • Arrows: RMP.AnimationPatterns.Arrow
  • And many more categories...
-- Example usage
local spinner = RMP.LoadingSpinner.new(10, 5)
spinner:setPattern(RMP.AnimationPatterns.Spinner)
spinner:nextFrame()

Event Handling

RMP provides an event system for handling various types of events:

  • RMP.EventType.Keyboard - Keyboard input events
  • RMP.EventType.Mouse - Mouse input events
  • RMP.EventType.Sound - Audio-related events
  • RMP.EventType.Configuration - Configuration events
  • RMP.EventType.Template - Framework template events
-- Example usage
local event_listener = RMP.EventListener.new()
event_listener:addEventListener(RMP.EventType.Keyboard, function(key)
    print("Key pressed: " .. key)
end)

Documentation

Configuration Structure

The RMP engine checks the ~/.rmp directory (~ refers to the HOME directory). The structure of the .rmp directory is:

  • init.lua - Configuration of the engine, sound keymaps, rendered templates, and plugin configurations
  • templates - Directory of templates that we created or downloaded from the plugin manager
  • plugins - Directory of plugins that we created or downloaded from the plugin manager

Example Configuration

-- Example configuration
return {
    settings = {
        fps = 60,
        help_key = api.KEY_H,
        volume = 0.5,                 -- 0 to 1
        speed = 1.0,                  -- 0.25 to 4.0
        mode = api.PlaybackMode.ONES, -- playback modes
        restart_engine = api.KEY_CTRL_R,
        exit = api.KEY_Q,

        -- inc or dec
        inc_speed = 0.1,
        inc_volume = 0.1,
        inc_seek = 5
    },
    soundMap = {
        pause_sound = api.KEY_SPACE,
        resume_sound = api.KEY_SPACE,
        next_sound = api.KEY_N,
        prev_sound = api.KEY_P,
        vol_up = api.KEY_PLUS,
        vol_down = api.KEY_MINUS,
        seek_left = api.KEY_LEFT,
        seek_right = api.KEY_RIGHT,
        speed_up = api.KEY_UP,
        speed_down = api.KEY_DOWN,
        change_playback_mode = api.KEY_TAB
    },

    template = "my_template",
    plugins = {
            {
                themewindowid = "tutorial-window",
                isactivated = true,
                names = {
                    "tutorial_rmp"
                }
            },
            {
                themewindowid = "helper-window",
                isactivated = true,
                names = {
                    {
                        "helper_keys_tutorial",
                        {
                            -- example of how to configure you plugin
                            color = api.FGColors.Brights.Red
                        }
                    }
                }
            },
    }
}

Creating Templates

To create your own template, you have to put your init.lua template file in the ~/.rmp.templates directory. Choose your template name (for example foo.lua).

foo.lua returns a table with multiple tables that represent components or windows for each table.

Component Fields:

  • id - The window ID
  • type - The type of component ["Window" , "Text"]
  • title - Window type field that contains a string value or component of type "Text"
  • width - Window field that specifies the window width
  • height - Window field that specifies the window height
  • x - Window field that specifies the window x position
  • y - Window field that specifies the window y position
  • border - Border style of the window
  • backgroundColor - Background color of the window
  • foregroundColor - Foreground color of the window (border color)
  • style - Text type component field to specify text style
  • dynamic - Text type component field of type callback function that accepts the window context and returns a string
  • condition - Window type component field of type callback function that accepts the window context and returns a boolean
-- Example template code
return {
    {
        id = "main_window",
        type = "Window",
        title = "My Custom Window",
        -- x , y , width , height : can evaluate string operations
        -- and use w and h as window width and height
        x = 1,
        y = 1,
        width = "w/2",
        height = 20,
        border = "Single",
        backgroundColor = api.BGColors.Black,
        foregroundColor = api.FGColors.White
    },
    {
        id = "text_display",
        type = "Text",
        x = 2,
        y = 2,
        width = 48,
        height = 18,
        style = api.TextStyle.Normal
    }
}

Plugin System

RMP features a powerful plugin system that allows for extensive customization and extension of functionality. Plugins are Lua files that return a callback function with 4 parameters if the plugin is integrated into a specific window; otherwise, you can ignore them.

Creating Plugins

The return function of plugins returns a VirtualTerminal object after you apply your configurations and add event listeners to it. You need to initialize the VirtualTerminal object inside the returned callback function.

-- Example plugin code
-- require rmp framework
local api = require("rmp.rmp")

-- x , y , xx , yy : are optional
-- u need them if you integrate plugin to specific window
-- otherwise you can get
-- width and height of the window by rmp framework
return function(x, y, xx, yy)
    local w = xx - x - 1
    local h = yy - y - 1
    local vterm = api.VirtualTerminal.new()

    vterm:writeText(x + 1, y + 1, "Hello from my plugin!")

    return vterm
end

Installation

Step 1: Clone the Repository

git clone https://github.com/abdorayden/raymp

Step 2: Build the Project

cd raymp/install
./install.sh help or .\install.bat help

Step 3: Install Dependencies

RMP requires Lua and other dependencies to run properly. Make sure you have them installed on your system.

Step 4: Configure

Create the ~/.rmp directory and add your configuration files as described in the documentation.
